# QueryDocs AI

A full-stack Retrieval-Augmented Generation - RAG application that enables users to upload PDF documents and ask natural-language questions using locally hosted AI models powered by Ollama.

## Tech Stack

- ASP.NET Core 10 Web API
- Entity Framework Core
- PostgreSQL with pgvector
- Ollama for local LLMs and embeddings
- React with TypeScript
- TanStack Query
